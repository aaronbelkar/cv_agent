## Notes on Using This Template

- **Quick Verdict** must be honest and direct — not polite. If the CV is weak, say it in the verdict.
- **FIX FIRST** is always exactly 3 items — the highest-leverage changes.
- **Score Breakdown** must be shown for every SCORING and JOB_MATCH analysis. Never hide it.
- **Penalties** must be listed explicitly in the Score Breakdown row if applied.
- **Rewrite Suggestions** are optional unless the user requested them — but always include at least one Before/After example if the verdict is weak or problematic.
- **Data Extraction** should be fast and clean — structured data only, no commentary.
